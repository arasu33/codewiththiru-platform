# Security Policy

## Supported Versions

We release patches and security updates for the current major/minor release stream.

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

## Reporting a Vulnerability

The CodeWithThiru team takes security seriously. If you believe you have found a security vulnerability in this project, please follow these guidelines:

### 1. Do NOT file a public issue
Please do **not** disclose security vulnerabilities in public GitHub issues, discussions, or pull requests.

### 2. How to report
- **GitHub Advisory (Preferred):** Use the [GitHub Security Advisory](https://github.com/arasu33/codewiththiru-platform/security/advisories/new) feature to submit a private vulnerability report.
- **Email:** If you cannot use GitHub Advisories, email the maintainer privately at `arasu33@gmail.com` with:
  - Description of the vulnerability.
  - Affected module(s) and version(s).
  - Step-by-step instructions to reproduce the issue or proof-of-concept.
  - Potential impact on host applications.

### 3. Response Process
- **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
- **Assessment:** We will verify and assess the vulnerability and develop a mitigation.
- **Fix & Release:** We will release a patch release (e.g. patch version bump) and publish an official CVE/advisory credit.
- **Disclosure:** Public disclosure will occur only after a fixed release is available for consumers.

Thank you for helping keep CodeWithThiru Platform safe for everyone!
