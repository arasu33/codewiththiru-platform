# Changelog

## [1.0.0-SNAPSHOT] - Unreleased
### Added
- `AnalyticsEvent`, `AnalyticsScreen`, `AnalyticsUserProperty` models.
- `AnalyticsManager` and `AnalyticsProvider` interfaces.
- `AnalyticsValidator` with automated PII scrubbing (Email, Phone, PAN, Aadhar, IP).
- `LogcatAnalyticsProvider` and `CompositeAnalyticsProvider`.
- Configuration models: `AnalyticsConfig`, `AnalyticsBatchConfig`, `AnalyticsPrivacyConfig`.
