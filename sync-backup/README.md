# :sync-backup
Enterprise Sync, Backup & Cross-Device Platform for CodeWithThiru ecosystem.

## Features
- Offline-first architecture
- Cloud sync (Incremental & Delta)
- Cross-device Conflict Resolution
- E2E Encrypted Backups
- Disaster Recovery
