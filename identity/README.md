# Identity Platform

An enterprise-grade, provider-agnostic Identity & Authentication SDK for the CodeWithThiru ecosystem.

## Modules
- Authentication (Email, Magic Links, Social)
- Session Management (Multi-device, Revocation)
- Token Platform (Access, Refresh, JWT rotation)
- Privacy & GDPR (Consent, Data Export, Deletion)
- Security (Biometrics, Device Trust, Risk Assessment)
