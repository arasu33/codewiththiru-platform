# API Guidelines

## Public Naming

Use:

CustButton
CustCard
CustDialog
CustAnalytics
CustAds

Avoid:

Button
Card
Ads

## API Design

- Explicit APIs
- Small interfaces
- Strong typing
- Backward compatibility

## Config Objects

Every module must expose configuration objects.

Example:

CustAdsConfig
CustAboutConfig
CustFeedbackConfig
