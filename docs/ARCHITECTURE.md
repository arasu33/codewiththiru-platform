# Architecture

The CodeWithThiru Platform utilizes a strict, highly decoupled multi-module architecture based on Clean Architecture and Unidirectional Data Flow (UDF) patterns. This design accommodates growing enterprise-level SaaS applications by organizing the codebase by layer and feature.

## Architectural Principles

1.  **Separation of Concerns:**
    Each module has a single, well-defined responsibility. The domain layer encapsulates business rules, the data layer handles persistence and network operations, and the presentation layer focuses entirely on UI and user interactions.

2.  **Unidirectional Data Flow (UDF):**
    State flows down, and events flow up. The UI state is immutable and generated by ViewModels, which react to user intents and domain model changes.

3.  **Dependency Inversion:**
    High-level modules do not depend on low-level modules; both depend on abstractions. Implementation details (like Retrofit or Room) are hidden behind repository interfaces located in the domain layer.

4.  **Modularization by Feature & Layer:**
    The project is split horizontally by architectural layers (Core, App) and vertically by feature (Feature modules). This allows multiple teams to work in parallel with minimal merge conflicts and significantly improves build times through build caching.

## Multi-Module Structure

Our modules are categorized into four primary types:

*   **App Module:** The main entry point. It binds all feature modules and core dependencies together, initializing Hilt, Firebase, and other application-wide components.
*   **Feature Modules:** Feature-specific presentation and domain logic (e.g., `feature:auth`, `feature:dashboard`). They depend on core modules but never on each other.
*   **Core Modules:** Reusable, single-purpose infrastructure modules (e.g., `core:network`, `core:database`, `core:designsystem`). These are foundational and heavily abstracted.
*   **Domain Modules:** Pure Kotlin modules containing business logic, UseCases, and Repository interfaces.

By isolating features and standardizing core infrastructure, the CodeWithThiru Platform enables a rapid, stable, and predictable development lifecycle for any SaaS product built on top of it.
